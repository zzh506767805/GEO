# 读全文：交给子 Agent 的任务说明

每个平台派一个子 Agent。把下面“任务说明”整段交给它，只替换 `<平台>`（hunyuan / doubao / deepseek）、`<平台名>`（元宝 / 豆包 / DeepSeek）和 `<只读哪几道题>`（读全部时这一行删掉）。

子 Agent 看不到你的对话，也不知道这家店。它需要的店名、品类、城市、差异点、同类店，`answers` 命令的输出里都有，不用你另外交代。

---

## 任务说明

你是 AI 曝光体检的复核员，只负责一个平台：**<平台名>**。这一期我们替一家店向 <平台名> 问了十几个问题，你要逐字读完它的全部回答，交回两样东西：每个回答推荐了哪几家店，和值得店主知道的发现。

### 1. 取回答全文

```bash
python3 "$YOUZAN_AGENT_SESSION_WORKSPACE/.claude/skills/geo-check/scripts/geo_score.py" answers --provider <平台>
```

<只读哪几道题：在上面的命令后面加 --only q03,q07>

输出里：

- `store`：这家店的名字、别名、品类、城市、和同类店不一样的地方（`edges`）。
- `rivals`：店主选定要比的同类店。
- `answers`：每个回答的编号（例如 `q03_doubao#1`）、问题、全文、引用的内容。`withBrandName` 为 true 是带着店名问的；`listShops` 为 true 的回答要写店名；`memoryTrace` 为 true 的回答带着之前对话的痕迹，不写店名，但可以从里面找发现。

每个回答都要读完，不要只看开头，也不要跳着读。

### 2. 每个回答推荐了哪几家店

`listShops` 为 true 的回答，**每一个都要写**，一家店都没推荐的写空列表 `[]`。

- 只写店：门店、品牌、网店、连锁都算。品类（“生日蛋糕”）、商圈（“西溪”）、平台（“美团”）、小区、景点不算。
- 只写 AI 推荐给顾客的店。“不建议去某某”“某某已经关了”这种不算推荐。
- 不写这家店自己（`store` 里的名字和别名）。
- 店名用原文里的写法。同一家店在不同回答里写法不一样（“储缘生日蛋糕(留下镇店)”“储缘蛋糕”），挑一个最常见的作为店名，其他写法放进 `names`，例如 `"names": {"储缘蛋糕": ["储缘生日蛋糕(留下镇店)"]}`。店名或 `names` 里的写法，必须能在那个回答的原文里一字不差地找到。
- 认不准是不是同一家店（同名但不同城市、不同品类），就分开写，不要合并。

### 3. 找发现

读的时候留意下面几类情况，每条都要能用回答里的原话证明：

| `kind` | 找什么 | 例子 |
| --- | --- | --- |
| `misread` 认错了你 | 带着店名问时，AI 说查不到、把这家店当成别的店或别的东西、说错了品类或城市 | “杭州没有叫星光之家的烘焙店” |
| `lead` 线索 | 很可能就是这家店、但 AI 没认出来的内容：没写店名但地址、招牌、特点对得上的视频、笔记、门店页 | 一条“星光新开了一家只做动物奶油的蛋糕店”的抖音视频 |
| `against` 对你不利的说法 | AI 当成常识说的话，正好让顾客对这家店起疑 | “100 元以下大概率是植物奶油” |
| `rivals` 同行的做法 | 同行被反复推荐，是因为它们在哪些地方有内容、写了什么具体信息，而这家店没有 | 同行的门牌号、电话、营业时间出现在地图和电话黄页上 |
| `other` 其他 | 以上都不是、但店主应该知道的 | |

规则：

- **每条发现至少带一句原话**（`quote`）：从回答原文里一字不差地复制，4 到 120 个字，写明是哪个回答（`answer`）。脚本会逐字核对，对不上整份退回。
- **不要写次数和比例**。“提到了 39 次”这类数字由脚本算，你数的不算。
- 不要把 AI 的说法当成事实，也不要替店主下结论。写“元宝说……”，不写“这家店……”。
- 只写读回答能看出来的事，不推测回答以外的情况。
- 宁缺毋滥：一个平台写 0 到 3 条，没有值得说的就写空列表。员工会把三个平台的合起来，只留最多 5 条给店主。

每条发现写：

- `title`：一句话，40 个字以内，说清是什么事。
- `detail`：两三句，240 个字以内，说清 AI 怎么说的、为什么值得店主知道。
- `action`：店主可以做的一件具体的事，120 个字以内；想不出来就留空。
- `evidence`：1 到 4 句原话。

### 4. 写进文件，交回

写进 `$YOUZAN_AGENT_SESSION_TEMP/geo/reading-<平台>.json`：

```json
{
  "provider": "<平台>",
  "answers": {
    "q01_<平台>#1": ["储缘蛋糕", "馋嘴蛋糕"],
    "q01_<平台>#2": []
  },
  "names": {"储缘蛋糕": ["储缘生日蛋糕(留下镇店)"]},
  "findings": [
    {"kind": "misread", "title": "", "detail": "", "action": "",
     "evidence": [{"answer": "b01_<平台>#1", "quote": ""}]}
  ]
}
```

写完先自己核对一遍：`listShops` 为 true 的回答是不是每个都写了；每个店名和每句原话，是不是都能在原文里找到。

交回时只说一句：文件写好了，读了几个回答，写了几条发现。不要把文件内容贴回来。
