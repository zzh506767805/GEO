# 改工作台、加页面：设计规范

商家让你把页面换个样子、加一块、加一页时，照这份来。

标准模板 `assets/page.html` 就是规范本身。新加的东西用模板里现成的样式和小函数拼，做出来要和别的页一样：商家分不出哪一页是后加的。

## 先想清楚

- **这一页回答商家的哪个问题。** 标题写这个问题问的东西，比如「竞品出现次数」。一页只回答一个问题。
- **放的是不是跨期的东西。** 只有某一期才有的分析放进那一期的报告，或者直接在对话里回答，不加页面。
- **数从数据块读。** 直接写在页面上的字不会自己更新，下一期就过时了。

## 不要放

- **补充说明。** 数字下面解释这个数的小字（「和监测设置里选的 3 家对得上」）、「口径：……」「说明：……」「注：……」、数据来源和算法的介绍、页面顶上的导语，都不要。商家问起，在对话里说。
- **状态和来历的小标签**，比如「等你确认」「你点名要的」「为 Q1 写的」。
- **「为什么」「怎么算的」这类折叠块**，以及塞了长段文字的鼠标提示。
- **新的颜色、字体、字号、圆角。** 也不要灰底大块、彩色背景条、渐变、阴影卡片和表情符号。
- **深色样式。** 页面只有浅色。
- **新开窗口和跳出页面的链接。** 不要写 `target`，用下面的链接函数。

能留下的字只有：标题、数和单位、店名和稿子标题这些名字、按钮上的字、空状态的一句话。

## 用什么拼

| 要放的 | 用 | 说明 |
| --- | --- | --- |
| 加一页 | 数据块的 `nav` 加一项（`id`、`title`、`icon`），模板 `PAGES` 里加 `pageXxx(root)` | 导航上的名字就是页面标题。图标用模板 `ICONS` 里有的（如 `users`、`list`、`eye`、`doc`、`store`） |
| 一块内容 | `card(标题, 数量, 右上角链接)` | 白底、细边框、圆角 12。数量只写「15 家」「4 篇」这种 |
| 几个大数 | `kpi(...)`，一排 3 到 4 个，放进 `row('c3 kpis', ...)` 或 `row('c4 kpis', ...)` | 数字下面那一行只能是会变的对比，比如「上一期 3 次」；写不出就空着 |
| 一列名单 | `table(...)`，或者一行一条的 `gap-row` | 数字列右对齐（`r`），排名、次数放最右 |
| 按类型筛 | `seg` 分段按钮 | 两种以上类型才放 |
| 分类 | `tag` | 只标类型（长文、小红书笔记），不标状态 |
| 外链 | `link(文字, 地址)` | 在客户端里交给系统浏览器打开 |
| 去工作台的别的页 | `nav(文字, 页面id)` | 嵌在报告里也能跳 |
| 同一个网站的预览 | `openPreview(地址, 标题)` | 在工作台里弹出来看 |
| 可以跟你说的话 | `sayBlock([...])`，最多 3 句 | 会收进右上角的「跟员工说」，不在页底另加一块 |
| 还没有数据 | `el('div', 'empty', '一句话')` | 只说还没有什么、什么时候会有，一句话 |

## 颜色和字

只用模板 `:root` 里的颜色：

- **底色**：白底 `--bg`。分区靠 1 像素细线 `--line` 和留白，不靠灰底。
- **字色**：正文 `--ink`；次要 `--ink-2`；辅助 `--ink-3`，只给数量、单位、时间用。
- **品牌蓝 `--brand`**：链接、选中、主按钮，以及一页里最需要看的那一个数。
- **好坏色**：`--ok`、`--warn`、`--bad` 只在真有好坏时用，比如被提到的次数变少了，不拿来装饰。
- **图表**：多种颜色按顺序用 `--c1` 到 `--c7`。

字号只有这几档：顶栏标题 18 加粗，卡片标题 15 中粗，正文 14，辅助 12–13，大数字 32。

## 改完自查

1. 截图看一遍，电脑宽 1280、手机宽 390。
2. 把页面上的字过一遍：除了标题、数、名字、按钮，还有没有解释性的句子？有就删。
3. 同步一次，看数字确实跟着数据块变了。
4. 点一遍页面上的链接，在客户端里都能打开。
