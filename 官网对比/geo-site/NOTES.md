# geo-site 版本说明

## skill 来源

本仓库自带：`digital-employee/definitions/ai-visibility-employee/skills/geo-site/SKILL.md`（最近一次修改的 commit：`8e56de0`）。原本用于给商家店铺做官网，页面委托 `youzan-application` 能力生成。

## skill 的关键要求（本次执行的部分）

- 跳过：`site-brief` / `set-site` / `publish` 脚本、委托“应用”能力、请商家确认、测试版/正式版流程（本环境不存在）。
- 第 2 节内容规范：一页从上往下按固定块排；只写资料里给的事实，没资料的块不放、不补；不写价格；不放评价/排名/奖项；不用“第一/最好/唯一”、不和别家比；常见问题一问一答、只用页面其他块里的事实；只用真实图片，生成的图不能画成产品/门店；页面最下面写“信息更新于 X 年 X 月 X 日”。
- 第 3 节交给“应用”能力的方案：整体感觉“干净、信息好找，像官方介绍页，不做成促销活动页”；一个页面、不用登录、无表单、不收集信息；文字直接写在页面里，不在打开时取数据。

## 设计决定

- 结构（店铺块 → 产品块）：这是谁（名字、一句话、是什么、适合谁/所属公司/在哪用）→ 能做什么（四块 + 和通用 AI 的区别）→ 怎么用（随口一问、AI 工作台连接器、多渠道、数字员工）→ 常见问题 → 了解入口 → 更新日期。顶栏锚点导航对应前四块。
- 配色：直接沿用龙虾客户端（示例/麦的日尝/ai-visibility.html）的主题变量：灰底 #f6f7f8、白卡片、文字 #1f2328、品牌蓝 #155bd4；深色模式随系统切换，变量同客户端（品牌蓝 #4d8dff）。深色下按钮底色单独压暗到 #2f6fe0，保证白字对比度。
- 字体：系统字体栈（PingFang SC / 微软雅黑），不加载网络字体，与客户端一致。
- 版式：最大宽度 1080px；首屏左文右“示意对话”卡（明确标注“示意”，不出现任何数字）；常见问题和事实用 dl 平铺、不折叠，方便人和 AI 直接读；手机端单列、卡片改横排图标。
- 动效：基本不做，只有锚点平滑滚动（尊重 reduce-motion）和按钮 hover。不用渐变大横幅、倒计时、徽章等促销元素。
- 图片：只用素材里的龙虾图标（base64，按原尺寸以内使用，不拉伸）；图标用内联线性 SVG。

## 长处

- 内容纪律强：只写给定事实、不写价格、不夸大、FAQ 用事实作答，天然适合 GEO（给 AI 一个可引用的出处），也规避了编造。
- “文字直接写在 HTML 里”“无表单无登录”这类工程要求明确，对搜索引擎和 AI 抓取友好。
- 块的顺序清晰，产出的是“资料页”，信息密度高、好找。

## 局限

- 它是内容/流程规范，不是视觉设计规范：配色、字体、版式、动效几乎没有指导，视觉质量依赖执行者和“应用”能力。
- 为店铺设计（门店、招牌商品、怎么买），用到 SaaS 产品上需要人工映射块。
- 刻意克制，页面偏朴素，缺少品牌感和视觉记忆点；没有结构化数据（JSON-LD）等 GEO 技术细节的要求。
