## skill 要求的流程（我都照做了）
1. 读 brief，列出只属于这个客户的东西（店铺后台连接、六句门店随口问、三家 AI 工作台、五大板块 16 项技能、四个渠道、AI 曝光专员、品牌蓝）。
2. 先写“论点”：每个区块对应一个论断加证据，没有论断的区块删掉（删了 draw 发下来的 list 区块）。
3. 用 `scripts/draw.mjs` 抽三个方向（one-motif / colour-chapters / product-performs），选了 **product-performs（产品自己演示）**，seed 790456469。理由：龙虾本身就是一段对话，素材里的六句问题就是它最真实的内容。
4. 想法句：“在这一页上，门店人员的六句随口一问，变成首屏那个真的能点的对话框。”页面上的那个可操作的东西：点任意一句，看龙虾会去查什么数据、查哪个范围、从哪查。
5. 先写文案再写结构；6. 按方向表构建；7. 用 `lint.mjs` + `inspect.mjs`（真浏览器，1440/768/390）过关；8. 看截图按 critique 评分改问题；9. 最后加动效。
- house rules：标题最多两行；不要眉标、等宽字体、01/02/03 编号、细分割线、渐变、静止阴影、玻璃、图标卡片，也不要奶油色配赤陶色或紫色；按钮只用一种形状。

## 设计决定
- **版式**：照方向表抽到的蓝图来做。首屏是“Column on one line”，所有内容挂在左起 27% 的竖线上，下面露出对话框。往下依次是：引言大段 + 四栏（它是什么 / 适合谁 / 在哪用 / 谁在做）、四条整行宽的开关带（四块托管，开了就整行变色并出一行说明）、固定住的界面片段（AI 工作台连接器，一共三种状态）、带控件的演示（四个平台的开关会改变回答范围）、AI 曝光专员用第一人称写的一封信（扇贝底边的纸）、问题索引加右侧答案、整屏品牌蓝收尾、色块拼成的页脚。
- **配色**：方向表发的是 Sand and moss，我保留了沙色底 #ddd6c6 和炭黑字，各种颜色的占比也照原样。苔绿强调色换成龙虾自己的品牌蓝 #155bd4，依据是 skill 的规则“主体有自己颜色时，保留比例、颜色取自主体”。
- **字体**：方向表发的是 General Sans（来自 Fontshare，只有拉丁字符）。这一页是中文，而且只允许用 Google Fonts，所以换成 Noto Sans SC，一个字族用 400/500/700 三个字重，参数照方向表（700、-0.02em）。
- **图像**：skill 要先在开放图库找真实图片，但 `assets.mjs` 连不上 Openverse/Commons/博物馆（网络被挡），而且这一页必须是单文件，所以照 skill 的兜底规则，用 HTML 画界面片段（加 `data-ui`）当主要图像。没有用 picsum 照片。
- **动效**：方向表点名的签名动作是 slow crossfade，我把它用在首屏对话框上：六句问题每 5.6 秒淡入淡出一次，用户一点就停，标签页隐藏时暂停，开了减少动态就不动。另外还有标题按行从遮罩里升起、各区块错开入场、开关和按钮按下时的反馈、固定片段的状态切换、FAQ 150ms 淡入淡出。所有动效都有 reduced-motion 兜底。
- **诚实**：对话里只说“要查什么 / 范围 / 来源”，不出现任何数字。页面上标了“对话为示意，不含真实经营数据”。

## 验收结果
- lint：0 FAIL 0 WARN。inspect：0 FAIL，剩 2 个 WARN。一个是 no-real-pictures：没有真实照片，因为网络连不上开放图库。另一个是 no-footage：没有视频，原因相同。
- 第一轮看图后修了：分段按钮的阴影（被判 button-fx FAIL）、占位文字对比度、字号种类太多、固定区块太空、平台演示面板空着一大块、手机端页脚色块顺序乱。
- 环境问题：沙箱里以 root 跑 Chrome 必须加 `--no-sandbox`，所以写了一个包装脚本通过 CHROME_PATH 传进去。

## 长处
- 流程很硬：用脚本抽方向，避免模型每次都回到“居中标题 + 三张卡片”的老套路；还有真浏览器量出来的禁用清单，以及看截图、打分、改三处的循环。最后页面确实没有常见的 AI 味装饰。
- 逼你先写“只属于这个客户的东西”和论点，页面结构就跟着内容走。

## 局限
- 很重：完整走一遍要读 2300 行文档，还要跑 Node 22 和 Chrome；依赖外网图库，离线时最核心的“真实图片”这一环就断了。
- 默认面向英文：抽到的字体只有拉丁字符，字号算法按西文字宽，中文页需要自己再换算。
- 方向表各部分会互相矛盾（首屏蓝图要求 27px 的小标题，方向本身要求 4–6vw），要靠优先级规则自己调和。
- 随机抽签带来的不确定性很大，换个 seed 就是另一张页面，不太好横向复现。
- 固定叙事加上每段 60–80vh 的高度，在整页截图里看起来很空。
