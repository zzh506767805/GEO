# 有赞龙虾官网 · DESIGN.md（方向 B「经营对话台」）

## 设计读取
读取为：品牌官网单页，面向连锁品牌 / 门店 / 本地生活 / 多渠道商家的老板与店长，用“店里人说话”的朴素语言，倾向对话式产品（Intercom）+ 染色层次（Stripe）。
拨盘：视觉冒险度 6（分屏不对称，但信任优先）· 动效强度 5（只做解释因果的动效）· 信息密度 4（每节短标题 + 短段 + 一个视觉）。

## 功能契约
- 存在理由：让商家知道有赞龙虾是什么、能替店里做什么、在哪里能用。
- 3 秒必得：有赞龙虾 = 商家的 AI 经营助手；用说话的方式问经营问题；查的是自己店的数据。
- 必须能完成：点“了解有赞龙虾”跳到官方产品页。页面不放表单。

## Build brief
- 目标情绪：先觉得“我店里的人就能这么问”，再明白“它连着我的店铺后台”。
- 灵感转译：借店长手机上的工作对话 → Hero 右侧是一个可点的对话台示意；全页问题都是可点的“随口一问”，点了就在对话台里演示。
- 签名动作：点任意一条“随口一问”，对话台出现提问 → 打字点 → 回答示意（无真实数字，明确标“示意”）。
- 反目标：居中 Hero + 三卡片；紫蓝光晕/渐变字；编造数据；卡片海；左侧竖线强调。
- 资产策略：无图像生成工具，龙虾图标 88px 原尺寸以内使用；Hero 视觉用高保真组件示意（三层深度：底纸 → 对话窗 → 浮动标签）。

## 排版
- 中文全部系统栈；JetBrains Mono 只用于西文/数字小标签和“16”大数字。
- H1 clamp(38px, 5.2vw, 66px) / 600；H2 clamp(28px, 3.4vw, 42px) / 600；正文 17px / 1.75；无负字距、无斜体。

## 组件与形状
- 按钮、问题 chip：4px 圆角（Intercom 近直角）；面板 8px。
- 深度：rgba(21,91,212,.22) 0 30px 45px -30px, rgba(0,0,0,.08) 0 18px 36px -18px（Stripe 染色双层，改染品牌蓝）。
- FAQ 用原生 details/summary。

## DNA 供体
- Intercom：暖白 #faf9f6 画布、燕麦边框 #dedbd6、按钮 4px / 卡 8px、等宽大写小标签、无阴影卡片靠边框分组。
- Stripe：远层染色 + 近层中性的双层阴影、负 spread 让阴影只向下。

## 动效
- ease-out cubic-bezier(.23,1,.32,1)；入场 translateY(10px)+opacity 320ms，只触发一次；按钮 :active scale(.97)；状态点呼吸；hover 仅限 (hover:hover)。
- prefers-reduced-motion：去掉位移和呼吸，保留即时切换。

## 响应式
- ≥960px 分屏；<960px 单列，对话台在标题下；375px 下 chip 换行、无横向滚动。
