# 有赞龙虾官网 · 六个设计 skill 对比

同一份内容素材（`_素材/内容素材.md`），六个子 Agent 各用一个 skill 做一页官网。每个目录里有 `index.html`、`NOTES.md`（skill 来源、做法、局限）和桌面、手机两张整页截图。

| 目录 | skill 来源 | 方向 |
| --- | --- | --- |
| `geo-site/` | 本仓库 `digital-employee/.../skills/geo-site` | 干净的官方介绍页，照搬龙虾客户端主题，有深色模式 |
| `frontend-design/` | anthropics/skills · dbd4588 | 整屏品牌蓝 + 黄油体大字问句 + 打印小票，辨识度最高 |
| `ui-ux-pro-max/` | nextlevelbuilder/ui-ux-pro-max-skill · 56ea9cf | 浅色玻璃拟态 + 橙色按钮，最像通用模板 |
| `taste-skill/` | Leonxlnx/taste-skill · f624f37 | 沙色底、超大字、竖线骨架的编辑型长页 |
| `qiaomu-design/` | joeseesun/qiaomu-design · ccd9cec | 暖白底 + 品牌蓝的“经营对话台”，另有四方向预览 |
| `emil-design-eng/` | emilkowalski/skills · 2d22863 | Vercel/Linear 式克制，重交互打磨，有深色模式 |

结论：正式官网建议用 qiaomu-design 那版打底；要记忆点看 frontend-design。

内容素材来自公开报道，本环境打不开原网页，没有逐字核对；页面里的对话都是示意，不含真实数据。
