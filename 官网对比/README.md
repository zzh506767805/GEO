# 有赞龙虾官网 · 三个设计参考的效果样例

`geo-site` 技能做官网时，员工从三个设计参考里挑一个（见 `digital-employee/definitions/ai-visibility-employee/skills/geo-site/references/design-index.md`）。这里是用同一份内容素材（`_素材/内容素材.md`）、分别照这三个参考做的有赞龙虾官网，给维护的人看三种方向的差别。

每个目录里有 `index.html`、`NOTES.md`（skill 来源、做法、局限）和桌面、手机两张整页截图。

| 目录 | 设计参考 | 来源 | 方向 |
| --- | --- | --- | --- |
| `qiaomu-design/` | 乔木设计（默认） | joeseesun/qiaomu-design · ccd9cec | 暖白底 + 品牌蓝的“经营对话台”；另有四方向预览 `design-previews/` |
| `frontend-design/` | 前端设计 | anthropics/skills · dbd4588 | 整屏品牌蓝 + 大字问句 + 打印小票，辨识度最高 |
| `ui-ux-pro-max/` | UI/UX 设计规范 | nextlevelbuilder/ui-ux-pro-max-skill · 56ea9cf | 浅色玻璃质感 + 橙色按钮，最像通用模板 |

这三个样例是在 SEO/GEO 指引写好之前做的，没有完全照 `seo-geo.md`：h1 里没有店名，没有结构化数据和规范链接，用了 Google Fonts，常见问题都是折叠的。看设计方向就好，不要当成 SEO 的样板。

内容素材来自公开报道，本环境打不开原网页，没有逐字核对；页面里的对话都是示意，不含真实数据。

另外还试过 taste-skill、emil-design-eng 和本仓库原来的 geo-site 直接出页面，没有留下来。
